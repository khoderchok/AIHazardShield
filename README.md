# 🔥 AI Hazard Shield

AI Hazard Shield is an AI- and IoT-based smart safety system developed as my Computer Engineering senior project. The system is designed to detect fire and gas hazards in real time by combining computer vision, environmental sensors, and a mobile monitoring application.

## 🎯 Project Objective

The main objective of the project is to improve fire and gas detection reliability by combining multiple detection methods instead of relying on a single sensor.

The system uses AI-based image analysis together with temperature and gas sensor readings to improve detection accuracy and reduce false alarms.

## 🚀 Main Features

* AI-based fire detection using computer vision
* Real-time temperature monitoring
* Gas detection and monitoring
* ESP32-CAM integration for image capture
* Multiple sensor inputs for more reliable hazard detection
* Real-time data synchronization using Firebase
* Mobile monitoring and control application
* Alerts when hazardous conditions are detected
* Automatic response mechanisms for detected hazards

## ⚙️ How It Works

1. The ESP32-CAM captures images of the monitored environment.
2. The images are analyzed using a YOLOv8 computer vision model to detect possible fire.
3. Temperature and gas sensors continuously monitor environmental conditions.
4. The system combines AI detection with sensor readings to make the detection process more reliable and reduce false alarms.
5. Detection and sensor information is synchronized through Firebase.
6. The React Native mobile application allows users to monitor the system in real time.
7. When a dangerous condition is detected, the system can trigger alerts and connected safety components.

## 📱 Mobile Application

The mobile application provides real-time monitoring of the safety system and allows users to view detection information and interact with the system remotely.

It was developed using React Native and Expo and communicates with the system through Firebase.
